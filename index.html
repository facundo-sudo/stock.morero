Lista de híbridos

El Excel debe tener las columnas Semillero, Híbrido y Grano (Girasol, Maíz o Sorgo). El archivo se lee en tu computadora y no se sube a ningún lado.

Clientes

El Excel debe tener la columna Nombre y, si querés, CUIT, Localidad, Teléfono y Correo.

Compras e ingresos

Suman stock: existencia inicial de campaña, compras, pedidos y mercadería consignada. Las devoluciones a semillero restan. Al importar desde Algoritmo: PED/OC → pedido; REM y FAC → compra; consignación → mercadería consignada; devolución → resta stock. Si un remito o factura corresponde a un pedido o remito anterior del mismo híbrido, pregunta para no sumar dos veces y llevar el saldo a recibir.

Ventas y reservas

Las ventas, reservas y pedidos descuentan stock; las devoluciones lo suman. Al importar desde Algoritmo: FAC y REM se toman como venta, PED como pedido y RDE como devolución. La página busca en la descripción el híbrido cargado (por ejemplo «ADV 5407») y, en girasol, la banda: G0, G1 y G2 → Banda 1; G3 → Banda 2; G3E y G4 → Banda 3. Si un remito o factura es del mismo cliente e híbrido que una operación anterior, pregunta si corresponde a esa, para no descontar dos veces y llevar el saldo a remitir.

Copia de seguridad

Todo lo que cargás queda guardado en este navegador. Si borrás los datos del navegador o cambiás de computadora, se pierde. Por eso conviene bajar una copia seguido.

Para pasar los datos a otra computadora o al celular: bajá la copia acá, mandate el archivo y en el otro equipo tocá «Restaurar una copia».
